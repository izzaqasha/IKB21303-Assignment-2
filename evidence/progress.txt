#### [STAGE 5] DEBUGGING ####
Status: COMPLETED

Problem:
- The extracted secret.txt file was initially empty.

Cause:
- The file size was stored using 8 bytes during the hiding process,
  but only 4 bytes were being read during extraction.

Original extraction:
file_size = int.from_bytes(data[6:10], "big")

Corrected extraction:
file_size = int.from_bytes(data[6:14], "big")

Result:
- Extraction now works correctly.
- Original secret data was successfully recovered.

### [STAGE 10.3] PIXEL DIFFERENCE ANALYSIS ###
Status: COMPLETED

Test images:

Stego: output/stego.png

1,000,000

Changed pixels:
115

Changed pixel percentage:
0.01%

Changed RGB channels:
197

Total channel-value difference:
197

Maximum channel difference:
1

Conclusion:
The pixel difference analysis confirms that the LSB
steganography process makes very small modifications
to the cover image. Only 115 pixels were changed,
representing 0.01% of the total pixels. The maximum
individual RGB channel difference was 1, which is
consistent with the LSB embedding method.

File-size observation:
The stego PNG was 17.28% smaller than the original
cover PNG. This does not indicate data loss because
the pixel-level analysis confirms that the images
have the same dimensions and only small LSB changes
were introduced. PNG re-encoding and compression can
produce different file sizes.
